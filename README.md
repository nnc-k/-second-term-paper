# Проект "Мониторинг самолетов"

Учебный проект по Python: сбор данных о самолетах над выбранной страной с использованием открытых API, сохранение в JSON, фильтрация и сортировка данных. Реализованы принципы ООП, SOLID, наследование, абстракция, инкапсуляция и обработка исключений.

## Функционал проекта

### Архитектура классов и модулей

- **AbstractAPI** — абстрактный базовый класс (ABC) для работы с внешними сервисами. Описывает интерфейс подключения (`_connect`), получения ответа (`_get_response`), координат страны (`get_country_bounding_box`) и списка самолетов (`get_aeroplanes`).
- **AeroplanesAPI** (наследник AbstractAPI) — реализация для API `nominatim.openstreetmap.org` (координаты) и `opensky-network.org` (самолеты).
- **AbstractSaver** — абстрактный класс для хранилищ. Задает методы добавления, получения и удаления самолетов.
- **JSONSaver** (наследник AbstractSaver) — класс для сохранения информации о самолетах в JSON-файл.
- **Aeroplane** — модель самолета с инкапсуляцией и валидацией. Поддерживает методы сравнения.
- **services** — модуль с бизнес-логикой (функции фильтрации по стране, высоте, сортировка и получение Топ-N).
- **user_interaction** — модуль для взаимодействия с пользователем через консоль.

### Основные возможности и атрибуты

- **Приватные атрибуты Aeroplane:**
  - `__icao24` — уникальный идентификатор (доступен через property `icao24`).
  - `__callsign` — позывной.
  - `__origin_country` — страна регистрации.
  - `__velocity` — скорость полета.
  - `__baro_altitude` — высота полета.
  - `__on_ground` — находится ли на земле.
- **Валидация данных:**
  - В `__init__` класса `Aeroplane` реализована проверка: `icao24` должен быть непустой строкой, `velocity` не может быть отрицательной, а `baro_altitude` не может быть меньше -500.
  - В `get_country_bounding_box` обрабатывается ситуация, когда страна не найдена (выбрасывается `ValueError`).
  - В `_get_response` обрабатываются сетевые ошибки (выбрасывается `ConnectionError`).

### Методы

- **AeroplanesAPI.get_aeroplanes(country)** — получает координаты страны, затем запрашивает самолеты в этих координатах и возвращает список словарей.
- **Aeroplane.cast_to_object_list(raw_data)** — класс-метод, который преобразует сырые данные из API в список объектов `Aeroplane`, отфильтровывая записи без `icao24`.
- **Aeroplane.is_faster_than(other)** и **is_higher_than(other)** — методы сравнения самолетов по скорости и высоте.
- **JSONSaver.add_aeroplane(aeroplane)**, **get_aeroplanes(criteria)**, **delete_aeroplane(aeroplane)** — методы для работы с JSON-файлом (добавление, фильтрация при чтении, удаление).
- **filter_by_origin_country()**, **filter_by_altitude_range()** — функции фильтрации списков самолетов.
- **get_top_n(aeroplanes, n)** — возвращает топ-N самолетов по высоте (сортировка DESC).
- **user_interaction()** — главная функция программы, которая запрашивает у пользователя страну, N, страны для фильтрации и диапазон высот, а затем красиво выводит результат в консоль.

### Магические методы

- **__str__** и **__repr__**: возвращают строковое представление объекта `Aeroplane` для удобного вывода в консоль.
- **__eq__**: позволяет сравнивать два самолета на равенство по их уникальному номеру (`icao24`).
- **__lt__** и декоратор **@total_ordering**: позволяют сравнивать самолеты по высоте полета (больше/меньше).

## Технологии

- Python 3.14
- Poetry — управление зависимостями
- requests — работа с API
- pytest, pytest-cov — тестирование и покрытие
- flake8 — линтер (PEP 8)
- black, isort — форматирование кода
- mypy — строгая проверка типов

## Установка и запуск

### Установка зависимостей
poetry install

### Запуск программы
poetry run python src/user_interaction.py

### Запуск тестов с покрытием
poetry run pytest

Отчёт о покрытии в HTML создаётся в папке htmlcov/. Открыть отчёт: htmlcov/index.html.

### Проверка кода линтерами
poetry run flake8 src tests
poetry run black --check src tests
poetry run isort --check-only src tests
poetry run mypy src
